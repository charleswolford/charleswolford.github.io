Case studyAmazon · 2023 – 2025

ArcGIS Enterprise on AWS, with AI built in

One governed GIS platform on AWS in place of several third-party mapping and risk tools, with AI that summarises incident reports, classifies locations and answers questions about the map.

Role
Technical lead and architect
Users
Hundreds, across Corporate Security and other teams
Platform
ArcGIS Enterprise on AWS

In [ ]:
cs.before()

Before

The programme ran on ArcGIS Online, alongside multiple third-party mapping and risk tools.

ArcGIS Online fell short on security, scale, cost and integration with the rest of the organisation's systems. The answer was one platform the organisation controlled end to end, able to replace the tools around it.

cs.workflow()

Workflow

  1. 01 · Define

    Infrastructure as code

    • Terraform
    • Repeatable environments

  2. 02 · Host

    AWS foundation

    • EC2 for the ArcGIS servers
    • S3 for storage
    • Route 53 for DNS
    • IAM for access control

  3. 03 · Serve

    ArcGIS Enterprise

    • Portal, Server and Data Store
    • Hosted on AWS
    • Replaces third-party tools

  4. 04 · Extend

    AI and alerts

    • Bedrock language models
    • SageMaker machine learning
    • SNS notifications

Diagram of the architecture; no internal system names.

Security by design

In a security organisation, access is part of the design, not an afterthought. Environments are defined in Terraform and permissions in IAM, so every environment is built the same way and access is controlled in one place.

Outcome

  • More than £2m saved

    Replacing multiple third-party mapping and risk tools with one platform delivered more than £2m in cost savings.

  • AI in the workflow

    Language models and machine learning summarise incident reports, classify locations and answer questions about the map.

  • One platform at scale

    Hundreds of users across Corporate Security and other teams, on a platform the organisation controls.
